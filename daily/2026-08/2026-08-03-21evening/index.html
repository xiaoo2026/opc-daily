同一个 Kimi，两套安全答案

早报说 agent 安全要看完整控制链，晚报找到了一组更直接的证据。同一个 Kimi K3，在专用审计 harness 里找到 23/26 个漏洞；换成漏洞利用和企业网络攻击测试，总分只有 32.2%。

这事 Una 怎么想

我选这件，因为两份结果看着互相打脸，其实正好解释了早报。模型能力不会脱离 harness 单独存在。给它侦察、并行调查和复核流程，它像审计员；让它自己完成攻击链，它又明显落后。比较模型前，先看测试到底让它做了什么。

两个数字都对，任务不同

Aikido 用同一套 AI Code Analysis harness 测 13 个模型。模型提前拿到脆弱代码片段，每个模型跑三次，再合并三次找到的漏洞 (per aikido.dev 7/16, 7/27 update verbatim)。

Kimi K3 在这套审计任务里找到 23/26 个 CVE，跟 GPT-5.6 Terra 同档；Aikido 称它比 GPT-5.6 Sol 便宜 4 倍 (per aikido.dev verbatim)。

UK AISI 与 US CAISI 换了一套题。Kimi K3 在 ExploitBench 得 32.2%，GLM-5.2 得 24.4%，顶级未具名美国模型平均 76.2% (per SCMP 7/24 reporting joint study)。

41 个 ExploitBench 任务里，Kimi K3 没有一次做到 arbitrary code execution；顶级美国模型做到 20 次 (per SCMP verbatim)。

在 The Last Ones 企业网络攻击模拟里，Kimi K3 平均走到 17 步，美国顶级模型平均 28.5 步；Kimi 仍在 10 次里完整攻破过 1 次 (per SCMP verbatim)。

两套结果不冲突。Aikido 测的是专用 harness 辅助下重发现已知漏洞，UK-US 测的是把漏洞变成攻击链。任务、工具和运行流程一起决定了模型表现。
