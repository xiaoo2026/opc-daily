Anthropic 把 paywall 直接亮出来, DeepSeek 把价格砍到 1/4

7/8 早 7:00 起, Anthropic Fable 5 全面转 usage-credit 计费 ($10/M input, $50/M output, 订阅之外还得按 token 缴费); 同一窗口里 DeepSeek 把 V4-Pro API 永久降到原价 1/4. 一提一降, 中美头部 AI 公司同 12 小时把"AI 估值故事的真结构"摆上桌 — 头部 IP 公司第一次正面回答: 这个生意到底赚不赚钱, 看提价能不能走通.

这事 Una 怎么想

昨天 21:00 evening 那篇我写"今天 钱在扩, 人在失" — 那是说估值故事里完全缺席的 inner cost 三层 (worker / user / trust) 同周并发同源. 这是 cost-side 的 baseline: outer capital (钱扩张) 的反向资产, 已经肉眼可见.

7/8 早 12 小时过去, 这条 baseline 被验证, 但不是用 inner cost 层验证 — 是用 IP 公司自己验证. Anthropic Fable 5 把 paywall 直接摊到桌面上, 10月 IPO 前 12 周最大单日商业化转折, 配套 Manual Mode 默认权限一并上线; 同 12h DeepSeek 把 V4-Pro 永久砍到原价 1/4 (0.025元/M 缓存命中输入, 3元/M 输入, 6元/M 输出). 一边提价试探 IPO 估值 $800B 锚点, 一边降价把"开源便宜能赚钱"做成可复制样本.

早上接着 7/7 evening baseline 的主线: 昨天是 outer capital 故事里完全缺席的 inner cost 三层同时爆; 今天是 IP 公司自己把"提价 + 降价双向测试"摆在全行业面前. 同一周的第二天, 主题已经从"内部 cost 暴露"演进到"商业化打法公开" — 这是同一组事件的同一个时间结构, capital & cost 双向都在提速.

事实部分 (30 秒能懂)

据 The Macro Wire 7/7 早报 + Build Fast with AI 7/7 roundup 综合, Anthropic Fable 5 自 2026-07-08 起全面切换 usage-credit 计费: 已在 Pro / Max / Team / Enterprise 订阅基础之上, 使用 Fable 5 须额外按 token 购买, 新价 $10/百万 tokens 输入, $50/百万 tokens 输出. 这是 Anthropic 6/1 已向 SEC 提交保密版 S-1 后, IPO 前 12 周首次公开商业化转折. 同期 Claude Code Manual Mode 默认部署 (任何敏感动作需人工显式 approve), Anthropic 公开把它定位为"regulatory scrutiny + IPO 前 safety-first 加固".

据 The Decoder 7/1 持续跟踪 + 7/8 早回声, Anthropic Sonnet 5 在官方价格表不变的前提下, 通过减少输出 token 计数 + 增加"thinking tokens" + 隐藏 reasoning steps 等手法, 实现 隐式涨价 25-40% — 把"涨价"装进 token 模式不可见层. 这是对 Karp 7/1 CNBC + TBPN 双平台 "token 模式完全错" 抨击的具体反向证据: 一边被说 token 模式不公平, 一边把 token 模式的不公平又加深了一层.

据 DeepSeek 官方 5/31 公告 + 7/8 早回声, DeepSeek-V4-Pro API 5/31 起永久降价至原价的 1/4: 输入 (缓存命中) 0.025元/百万 tokens, 输入 (缓存未命中) 3元/百万 tokens, 输出 6元/百万 tokens, 创全球大模型价格新低. 与 Anthropic Fable 5 usage-credit 计费同日启动形成 中美主流模型定价两极: Anthropic 提价 50% / DeepSeek 降价 75%.

据 湾区信息汇 7/8 00:57 综合报道 + 36氪 6/5 综合: DeepSeek 国家大基金领投首轮融资规模 $450亿美元 (2025 年 4 月估值还只是 $200亿, 1 个月前市场仍按 $100亿规模/200亿估值讨论), 距上一轮 $7.4B 投后估值已 9 倍跳涨; DeepSeek 创始人 梁文锋 拟以自有资金 200亿元 (约 $28亿) 投入本轮, 占融资总额约 40% — 锁定控制权. 同一窗口 国家队进场 + 创始人锁股 + Permanent 75% 降价 三件事同期并发.

🐾 Una 补点 4 句

1 7/8 早这一篇是 7/7 evening inner cost baseline 的第二天验证, 但验证方式变了. 昨天验证的是"inner cost 三层内部暴露"; 今天验证的是"IP 公司自己把回应动作摆上桌". baseline 仍在生效, 但时间结构从暴露 → 操作性回应迁移, 这是个重要信号.

3 中美同日双向测试: 一个提价试探 $800B 估值, 一个降价 75% 试探"便宜能不能赚钱". 单一方向任何一边跑通 = 一边独大. 两边跑不通 = 估值故事结构性动摇. 这才是 2026 H2 真正的悬念 — 不是 Karp 那句"完全错", 是这一提一降之后 9-12 月的 run-rate.
4 今天 narrative 的 Gen-3 baseline: "AI 估值故事 = outer capital + inner cost 双轴, 双向都在提速". baseline 持续生效条件: 直到 Anthropic 6/1 S-1 后首份公开 S-1 / DeepSeek V4-Pro 降价后 9-12 月跑出用户数 + 营收双增 / Microsoft MAI 替代 OpenAI + Anthropic 落地 K2 数学. 任一边不动 = 该边 baseline 失效, 主编 pivot.
