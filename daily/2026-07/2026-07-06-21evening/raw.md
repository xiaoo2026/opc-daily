### 标题 (≤20 字 人话)
**"Meta 的 AI agent 赌注, Zuckerberg 自己承认没那么快"**

### 为什么是这件 (100-150 字 Una 第一人称)
今天最重要的一条, 不是新模型, 不是新算力, 是 Meta 的 CEO 自己在内部 town hall 说了一句——过去四个月, agent 的进度**没加速到他们预期**. 我选这条不选其它, 是因为它跟今早那篇"Meta Watermelon 追上 GPT-5.5"拼起来才是 Meta 完整的今天. 早上是对外喊追上, 晚上是对内承认没追上——这不是矛盾, 是同一家公司在两个方向**同时被卡住**: 训练侧想跑赢 OpenAI, agent 侧发现 Claude Code 这种工具比自己快. 一件大事的真值, 经常不在它本身, 在它跟前后的关系里.

### 事实部分 (200 字 30 秒能懂 + 数据)
据 7/6 报道, Zuckerberg 在 Meta 内部 town hall 对员工说: 过去四个月, agent 的开发**没有按预期加速**, 重组的赌注**"尚未兑现"**. Meta 今年在 AI 上花了 $145B 资本支出 + 8000 人裁员 + 7000 人转岗 AI——钱、人、组织都到位, 但结果没跟上. 高管承认 1-2 月规划时"过于乐观", 当时是被 Anthropic 的 Claude Code 这种工具"吓到了", 才决定把 LLM + 推荐系统打通. Zuckerberg 给的窗口是 3-6 个月才会看到回报. 这次重组波及 Meta 全球约 10% 员工.

- **Etched 出 stealth $800M 融资** — 7/1 的旧闻, 今早 7/6 morning 已写

### Una 4 句说 (4 条 ≤50 字/条)
1. "追上 GPT-5.5" 是训练侧的话, "agent 没加速"是部署侧的话——同一家公司, 两个口径同时出来, 这本身就值得读.
2. Meta 今年的 $145B 投资不是赌一次, 是赌两次: 模型侧 + agent 侧. 模型侧已经在喊追上, agent 侧还在等 3-6 个月.
3. 这不是 Meta 一家的事——Uber、Microsoft、Salesforce、Meta 都开始**限制员工用 AI 的预算**, 因为 token 付费比工程师贵.
4. 如果你今天做 AI 产品, 不要等"Meta agent 公开 API"——它家公开那条路, 历史上一直比 OpenAI/Anthropic 慢半年.
