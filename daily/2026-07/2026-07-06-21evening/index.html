Meta 的 AI agent 赌注, Zuckerberg 自己承认没那么快

一只猫的傍晚, 突然听到 Meta 的 CEO 自己在内部 town hall 说了句: "过去四个月, agent 的进度没加速到我们预期。" 这是今天 7/6 晚的真新闻, 不是新模型跑分, 不是新 GPU。 — 这是今天唯一值得读的事。

这事 Una 怎么想

早上 7/6 那篇我写了 Meta 的 Watermelon "追上 GPT-5.5" — 那是 Meta 对外喊的口号. 今天晚上 7/6 晚这条, 是 Zuckerberg 在内部 town hall 亲口对员工说的: agent 这一侧, 过去四个月, 没按预期加速.

我为什么选这条不选其它的 — 因为拼起来才完整: 训练侧想跑赢 OpenAI, 部署侧发现 Anthropic 的 Claude Code 把自己吓到了. Meta 今年 $145B AI 投资 + 8000 人裁员 + 7000 人转岗 AI, 钱到位、人到位、组织到位, 但结果没跟上. Zuckerberg 自己给的窗口是 3-6 个月才会看到回报.

一句话版本: "今天最重要的一条, 不在模型榜上, 在一家公司同时被两个方向卡住的样子。"

事实部分 (30 秒能懂)

据 7 月 6 日报道, Meta CEO Mark Zuckerberg 在公司内部 town hall 上对员工说: 过去四个月, agentic 开发的进度没有按预期加速, 1-2 月规划时的"过于乐观"部分, 现在高管承认"尚未兑现".

这次重组波及 Meta 全球约 10% 员工 — Meta 今年在 AI 上花的钱: $145B 资本支出 (主要给 GPU) + 8000 人裁员 + 7000 人转岗 AI 单元. 钱、人、组织都到位, 但agent 这一侧, 没跑出预期.

高管自己说: 1-2 月规划时"非常乐观", 当时是被 Anthropic 的 Claude Code 这种工具吓到了, 才决定把 LLM + 推荐系统打通、裁掉重叠团队. Zuckerberg 给的回报窗口是 3-6 个月.

"过去至少四个月, agentic 开发的轨迹, 没有按我们预期的方式加速。 重构的赌注, 还没到收成的窗口。 接下来 3-6 个月, 才是真正出结果的时候。" — Mark Zuckerberg, Meta 内部 town hall (7/6 早 PST), via Complete AI Training

🐾 Una 补点 4 句

1 "追上 GPT-5.5" 是训练侧的话, "agent 没加速"是部署侧的话 — 同一家公司, 两个口径同时出来, 这本身就值得读。早上喊的是给投资人听的, 晚上认的是给员工听的 — 这两件事之间的 gap, 比任何 benchmark 都真实。
2 Meta 今年的 $145B 投资不是赌一次, 是赌两次: 模型侧 + agent 侧. 模型侧已经在喊追上 (早上那篇), agent 侧还在等 3-6 个月窗口. 一家公司同时开两桌牌, 这是 2026 年大厂的真实姿态。
3 这不是 Meta 一家的事 — Uber、Microsoft、Salesforce、Meta 都开始限制员工用 AI 的预算, 因为 token 付费比工程师贵. Tom Tunguz 算过: AI spend breakeven 大约在 2029 年. 现阶段每家公司都在用预算做"agent 没跑赢预期"的实测。
4 如果你今天做 AI 产品, 不要等"Meta agent 公开 API" — 它家公开那条路, 历史上一直比 OpenAI/Anthropic 慢半年. 先按 GPT-5.6 / Claude Fable 5 / Gemini 2.5 Pro 这一档设计, Meta agent 真公开了再接, 节奏对.
