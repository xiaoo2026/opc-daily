2. 安全攻防：AI 两侧同时进入「工业级」

AISLE 用 AI 找到 12/12 OpenSSL 零日漏洞（LessWrong 1/27/2026 详细复盘）——防御侧首例"全收"案例：

  • OpenSSL 1/27 公告 12 个新零日，全部由 AISLE AI 系统独立发现
  • 2025 全年 OpenSSL 14 个零日 CVE 中 13 个由 AISLE 找出
  • curl 因 AI 生成垃圾报告取消 bug bounty 之前，AISLE 提交了 5 个真实 CVE + 30+ 问题，24+ curl PR 署名 Stanislav Fort
  • 3 个零日藏了 25-27 年（1998-2000 时代代码），1 个 CVE-2026-22796 比 OpenSSL 项目本身还老（继承自 SSLeay 1990s）
  • OpenSSL 3.6.1 修复中 5 个补丁由 AISLE AI 系统直接提议
  • OCB 模式留下未加密/未认证的尾字节（密码学 bug）

AISLE 方法论：扫描 → 分析 → 分类 → 利用构造 → 补丁生成 → 补丁验证 全链路 AI 闭环，人类只做"目标选择 + 高级飞行员监督"。已整合形式化方法（symbolic/concolic、Z3、property-based）。

Anthropic Mythos 修复进度：Mythos 报告的 530 个高/严重严重漏洞中 75 个已修复、65 个发公开公告。Anthropic 自我评价"可能还在低估修复数量，因为部分漏洞无公开公告就被修复"。Mythos 发现速度已经"超过安全生态系统的吸收能力"。

Microsoft Exchange 零日 CVE-2026-42897 已在野利用：影响最新 Exchange Server 2016 的欺骗漏洞。Microsoft 描述为"up-to-date Exchange Server 2016 spoofing vulnerability"。Build 2026 同期最扎眼的"Microsoft 自家后院起火"。
