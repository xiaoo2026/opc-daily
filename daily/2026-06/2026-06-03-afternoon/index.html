腾讯云 DeepSeek-V4 系列最高降 97.5%，6/3 00:00 生效

模型 / 项目调价前调价后降幅
V4-Pro 推理输入0.012 元/千 tokens0.003 元/千 tokens-75%
V4-Pro 推理输出0.024 元/千 tokens0.006 元/千 tokens-75%

关键看点：缓存命中降 97.5%——RAG 检索、多轮对话、长上下文文档读都是缓存命中场景。一个企业知识助手每天反复读取百万级 token 内部文档，原来 0.001 元/千 token × 100 万 token = 1 元/天，调价后 0.0025 元/天——Agent 时代的高频场景成本直接击穿。

为什么是"Agent 时代"价格战：5/22 DeepSeek 先把 V4-Pro 永久降至 1/4 原价；5/27 小米 API 永久降价最高 99%；5/22 智谱 GLM-5.1 高速版 API 跑出 400 tokens/s——5 月起国产模型就在"按厘计价"层贴身肉搏，6/3 腾讯云把缓存命中打到原 1/40，是把价格战从"聊天"层面推到"Agent"层面。
