OpenAI 模型 6/1-2 GA 登 AWS Bedrock：价格对等 + 使用量计入 AWS 承诺消耗

来源：OpenAI Blog / AIToolsRecap | 2026-06-01 → 06-02
OpenAI 4/28 在 AWS Bedrock 限免预览后，6/1-2 正式 GA：GPT-5.5 + GPT-5.4 + Codex 全部上线。价格 = OpenAI 一方价格（无 AWS 额外收费），使用量计入 AWS 已有 EDP 协议承诺消耗。GPT-5.5 在 US East (Ohio)，GPT-5.4 在 US East (Ohio) + US West (Oregon)，Codex 覆盖 CLI/桌面/VS Code/JetBrains/Xcode 集成。走 Bedrock 下一代推理引擎的 Responses API，完整 AWS 安全控制（IAM/PrivateLink/CloudTrail/加密）。叙事意义：大型 AWS 客户（年承诺消耗数百万美元）现在可以把 OpenAI API 消费吸进 AWS 承诺消耗，Azure 的"独家"优势正式结束。配合 Build Day 2 "Windows = Agent OS"——OpenAI 把模型卖给 Microsoft 的最大对手，云分发与操作系统层开始分叉。

GitHub Copilot 6/1 token 计量引爆：4.7M 用户账单 25x-50x 反弹

来源：TechTimes / TechCrunch / MLQ.ai / WindowsForum | 2026-05-30 → 06-01
GitHub 6/1 凌晨 0 时正式把 Copilot 改成 GitHub AI Credits——1 credit = $0.01，按 token 消耗计费，替代了原来的 flat-rate premium request。4.7M 付费订阅者一夜之间从"固定月费"变成"按消耗"。开发者报告：单次 agentic 编码会话消耗 $30-$40 credits（一个 Pro 用户的 $10 月度额度一次性用完）；社区帖 400+ 评论近 900 反对票。最大成本冲击来自 agentic 工作流、大上下文窗口、premium 模型、重复迭代、PR 审查自动化——不是普通内联补全。这是 Microsoft 在 Build Day2 加 agentic 能力的同步副作用——agentic 价值 vs agentic 成本的张力在 6/3 全面爆发。

xAI Grok Build beta 发布：编码 agent 三方争霸正式成型

来源：xAI News / AIToolsRecap / CIO Dive | 2026-06-03
xAI 发布 Grok Build——终端 TUI 编码 agent，基于 Grok 4.3，对 SuperGrok ($30/月) 和 X Premium+ 用户开放。设计与 Claude Code（终端原生）更接近，不走 Codex（桌面应用 + 云优先）路线。关键差异化：Grok Build 对 X/Twitter 平台全数据流的原生访问——不只是"偶尔返回 X 帖子的 web 搜索"，对社区信号实时的编码任务特别有用。算力限制：xAI 据说只用了 Colossus 算力的 11% 给 Grok 模型——随算力释放，Grok 模型仍有大幅提升空间。6 月 3 日连发：6/2 Composer 2.5（xAI 编码模型） + 6/3 Grok Build（编码 agent 工具），xAI 在编码赛道从模型到工具全线对标 Anthropic/OpenAI。
