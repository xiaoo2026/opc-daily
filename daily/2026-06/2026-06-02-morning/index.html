来源：36氪 / 量子位 | 2026-06-01
微软宣布 6 月 30 日前取消 Experiences + Devices 部门（Windows、Microsoft 365、Outlook、Teams、Surface）的大部分 Claude Code 授权，工程师被要求迁移到自家 GitHub Copilot CLI。Claude Code 进入微软内部仅 6 个月。导火索是 Axios 报道：一家企业单月烧掉 5 亿美元 Claude 账单（约 34 亿元人民币）——因未设用量上限，老板给员工开通企业授权后 token 持续燃烧。Uber CTO 透露：工程师4 个月烧光全年 Claude Code 预算。Uber COO 公开表态："AI Token 消耗与最终发布的有价值产品之间，似乎并不存在明显的线性关系。"

亚马逊取消内部 AI 使用排行榜——员工为冲榜疯狂刷 Token。Meta收紧相关激励，从"多用多刷"转向关注实际产出。Duolingo原计划将 AI 使用纳入员工绩效考核，因员工质疑"是否必须为了使用 AI 而使用 AI"而撤回决定。CEO："感觉我们不是在为实际结果负责，而是在试图强推一些并不总是适合的东西。" AI 第一次变成了财务问题。

来源：21财经 | 2026-06-01

arXiv 论文：统一十年 AI 鲁棒性研究——三种主流方法本质同一件事

来源：arXiv / AI 周报 | 2026-06-01
新论文给出形式化证明：对抗训练、认证防御、随机平滑三种主流 AI 鲁棒性方法在数学核心上其实都在计算同一个东西——Gram 矩阵。这一结论可能颠覆过去十年 AI 安全研究的认知，提示研究者关注"问题等价性"而非堆叠新方法。
