### 🟢 Google 6/10 DiffusionGemma——26B MoE / 3.8B 激活 / 单卡 H100 1000+ tok/s / 18GB VRAM 可装（morning 角度 #3 案例 A）

**事件核心**（Google Blog 6/10 + Cryptobriefing 6/10 + X @testingcatalog 6/10 同步英文）：

**DiffusionGemma 6/10 发布**（Google Research Brendan O'Donoghue + Sebastian Flennerhag 联名）：

| 维度 | 规格 |
|------|------|
| **架构** | 26B Mixture of Experts（MoE），**3.8B 激活参数** |
| **基础** | Gemma 4 家族 |
| **技术** | 整合 Gemini Diffusion 研究 / 文本扩散 |
| **推理** | **单卡 NVIDIA H100 1000+ tok/s** / RTX 5090 700+ tok/s |
| **显存** | **量化后 18GB VRAM**（高端消费级 GPU 可装）|
| **并行** | 单次 forward pass **并行生成 256 tokens** |
| **许可证** | Apache 2.0 |
| **范式转移** | **从自回归逐字生成 → 文本块并行生成** |

**核心技术差异**（morning 主动技术解读）：
- **传统 LLM**：自回归（autoregressive）逐字 / 逐 token 生成 = 内存带宽瓶颈
- **DiffusionGemma**：**整块文本并行生成** = 计算瓶颈（**将 decode 瓶颈从内存带宽转移到计算**）
- **速度优势**：**4× 自回归 LLM**（同硬件）
- **质量**：通过 Gemini Diffusion 研究继承，6/10 Google 公开评测显示与同规模自回归 LLM 持平

**对 AI 行业 6 月暗线意义**（morning 主动关联 6/8 morning "Tokenomics 量化研究 165 分" + 6/10 21evening "Is Grep All You Need? Agent Harnesses 154 分"）：
- **6/8 morning #165 Tokenomics** = "Token 在代理软件工程中用在哪" = "自回归逐字生成的代价"
- **6/10 21evening #154 Is Grep All You Need?** = "代理是否需要更多自回归生成"
- **6/10 DiffusionGemma 26B MoE 4× 加速** = "自回归逐字生成不是唯一范式"
- **三者共同构成 2026 H1 推理范式转移暗线**：从"扩大自回归模型"到"扩散 + 稀疏激活 + 并行生成"
