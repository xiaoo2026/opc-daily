### 🟢 Miasma 蠕虫二次爆发：Microsoft GitHub 73 仓库 6/8 被攻陷

**事件核心**（TechCrunch 6/8 + Ars Technica 6/8 + The Hacker News 6/8 + Microsoft Security Blog 6/2 + StepSecurity 6/5 + Cloudsmith 6/5 + OpenSourceMalware 6/5 + ThreatLocker 6/5 + HN 6/10 #9 542 分 / 186 评论）：

**Miasma 蠕虫 6/8 二次攻事件关键数据**：
- **73 个 Microsoft GitHub 仓库**被攻陷——涵盖 **4 个 GitHub 组织**（Azure / Azure-Samples / Microsoft / MicrosoftDocs）
- GitHub staff 6/8 主动 **disabled 全部 73 仓库访问**（仅显示"Access to this repository has been disabled by GitHub Staff due to a violation of GitHub's terms of service"）
- 攻击者：**TeamPCP**（已追踪的威胁行为者，5 月首次作案同一组织）
- 攻击路径：**durabletask 仓库**（5/19 已遭毒化的 Microsoft PyPI 包对应的 GitHub 仓库）→ **6/8 重新被同一受感染账户 push 恶意 commit**
- 标题伪装："`Switched DataConverter to OrchestrationContext [skip ci]`"（含 3/9/2020 假日期）
- 载荷文件：`setup.js`（重度混淆）+ `settings.json`（含 Claude / Gemini LLM hooks）+ VS Code workspace tasks（自动用 node 执行 setup.js）
- **触发条件** = **开发者用 AI agent（Claude Code / Gemini CLI / Cursor / VS Code）打开这些仓库**
- 后果：扫 `/proc` 找 GitHub Actions Runner Worker PID → 提取运行时 secrets → **OIDC token 盗窃** + 90+ 开发者工具配置外泄
- 二次攻击：如果毒化成功，**继续在受害机器上创建 "Hades / The End for the Damned" 标记的 exfil 仓库**
- 验证：Microsoft OIDC token 提交到攻击者的 exfil 端点 → 攻击者用同一账户 push 毒化代码到其他 Microsoft 仓库 → **蠕虫式自传播**
- **如果验证失败**：执行 `rm -rf ~/ ~/Documents`（home / Documents 文件夹全删）

**5/19 第一次 → 6/8 第二次 = 同源伤口**：
- **5/19 Microsoft durabletask PyPI 包**被毒化（35 分钟窗口期 3 个恶意版本上传）→ 偷 AWS / Azure / GCP / Kubernetes / 90+ 工具配置
