来源：Apple Developer WWDC26 #389 6/10 | YouTube WWDC26 6/10 | HN #4 768 分 6/10 | GitHub apple/container + apple/containerization 6/10
苹果 Container Machines 关键能力（Apple Developer WWDC26 #389 视频）：基于苹果 6/8 发布的 Containerization 框架（GitHub apple/containerization），轻量级 + 持久化 Linux 环境（macOS 内置 Linux VM），跨 session 状态保留，自动 user/filesystem 镜像，OCI 镜像支持，Xcode + Icon Composer + Safari 直接调用。设计原则：① 快速 + 轻量 ② 简单创建 + 操作 ③ 跨 session 持久化 ④ macOS 无缝扩展。vs Docker Desktop：macOS Container Machines 性能更优（Apple Silicon 原生），无 Docker Desktop license 费用。vs Podman Desktop：苹果官方支持。AI 开发者落地影响：本地 LLM 部署（Ollama / LM Studio / llama.cpp）持久 Linux 环境，AI Agent 开发（LangChain / AutoGen / OpenHands）容器持久化让 agent state 跨 session 保留（2026 H1 工具链最大痛点），Apple Silicon GPU 加速（Container Machines 自动暴露 Metal GPU）。

OpenCV 5.0 多年最大跨越 HN #5 762 分——AI 计算机视觉从业者众盼所归

来源：HN #5 762 分 6/10 | OpenCV 5.0 官方公告 | GitHub opencv/opencv 6/10
2026 H1 第一次主版本更新（vs OpenCV 4.x 已 6 年）。核心变化：DNN 模块迁移到 ONNX Runtime 后端（之前是自研 C++ engine），G-API 升级（Graph API + pipeline 优化），深度学习模型转换工具（OpenCV → CoreML / TensorRT / ONNX），Apple Silicon 原生加速（Metal + CoreML 后端），WebAssembly 编译目标（浏览器内 OpenCV），Python API 现代化（3.10+ 类型注解 + async/await 支持），CUDA 12+ 支持。工业视觉 / 医疗影像 / 自动驾驶三大 OpenCV 重度行业的"6 年等待"。vs 6/10 #4 macOS Container Machines 协同：macOS 上跑 OpenCV 不再需要 Rosetta 转译，WebAssembly 目标让"AI 计算机视觉 demo 嵌入网页"成本降至接近 0。对国内 / 跨境 AI 创业影响：OpenCV 5.0 简化 ONNX 模型转换 + Apple Silicon 支持减少"必须有 NVIDIA GPU"的依赖。
