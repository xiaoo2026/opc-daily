2. 安全漏洞密集披露：AI 辅助零日获证实，多框架中招

⚠ 全球首例：AI 辅助零日漏洞在野利用获证实

Google威胁情报团队（GTIG）5月确认，威胁分子使用AI模型发现并生成零日漏洞（2FA绕过），代码特征高度符合LLM生成模式。Python脚本实现了针对开源Web管理工具的2FA绕过漏洞利用链。GTIG高置信度评估：这是全球首例AI辅助零日漏洞在野利用记录，标志着AI网络武器化进入实用阶段。

Cohere Terrarium 沙箱逃逸：Python沙箱 Terrarium（Cohere AI 开发，用于运行 LLM 生成代码的 Docker 容器）发现严重漏洞。根因：Pyodide WebAssembly 环境中 JavaScript 原型链遍历，可实现任意代码执行，以 root 权限运行主机进程。

Claude Code 安全漏洞（2月披露，5月回顾）：

  • CVE-2026-21851（CVSS 8.7）：用户同意绕过漏洞，在新目录启动时可通过未信任项目 Hook（.claude/settings.json）注入任意代码执行
  • CVE-2026-21852（CVSS 5.3）：信息泄露漏洞，恶意代码库可设置 ANTHROPIC_BASE_URL 指向攻击者控制的端点，在显示信任提示前泄露 API 密钥

MCP 设计缺陷（4月）：OX Security 研究发现 Anthropic MCP 架构存在"设计级"弱点，Python/TypeScript/Java/Rust SDK 均受影响，通过 MCP STDIO 的未认证/已认证命令注入可实现 RCE，影响所有运行 MCP 实现的系统。

PraisonAI CVE-2026-44338：CVSS 7.3，Flask API 服务器默认认证禁用，漏洞公开后4小时内即有在野利用尝试。

来源：The Hacker News、CVE.org、OX Security | 2026-02/04/05
