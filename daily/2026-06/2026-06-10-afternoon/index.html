谷歌 Gemini 3.5 Live Translate 6/9 23:33 BJT 正式发布——实时语音互译 70+ 语言

事件核心（IT之家 6/9 23:33 + 淘宝教育 6/9 + 新浪财经 6/9 + MyZaker 6/9）：

核心能力：

  • 自动识别 70+ 种语言
  • 保留说话者语调/语速/音高（vs 传统翻译"播音腔"）
  • 连续生成 + 无需等句结束（在"等待更多上下文"和"即时翻译"之间平衡）
  • 抗噪能力强（嘈杂/复杂/不可预测环境）

模型特性：

  • 所有生成的音频都加入 SynthID 人耳不可察水印（便于追踪与验证）
  • 多语言输入无需手动调整设置

产品落地：

层级细节
开发者Gemini Live API + Google AI Studio 可用公开预览版
企业Google Meet 中先以预览版体验，语种从 5 种扩至 70+ 种，覆盖 2,000+ 组合
C 端Android + iOS Google 翻译 App 同步上线
Android 专属"聆听模式"：像接电话一样把手机贴到耳边直接通过手机听筒收听翻译

潜在合作（已确认）：Grab 叫车平台据传正在测试，用于改善司机-乘客多语言沟通

对比与意义：

vs OpenAI Voice Mode：保留语调/语速/音高 vs OpenAI 偏"标准化"——Gemini 3.5 Live 在"真人感"上突破

vs Meta SeamlessM4T：单模型端到端 vs 谷歌模块化 Live API

2026/3/17 OpenAI Voice Engine 商用化遇阻 + 6/9 谷歌 Live Translate 落地——实时语音互译从"技术展示"进入"消费级 App 默认功能"阶段
