🤖 模型动态

🔵 OpenAI 开源模型正式发布 + Claude 4.1 同天登场

5月28日，OpenAI 正式发布两款开源推理模型：gpt-oss-120B（生产级，120B参数）和 gpt-oss-20B（桌面级，20B参数），采用 Apache 2.0 许可，可商用、可自由构建、可微调。同日 Anthropic 发布 Claude Opus 4.1。GPQA 钻石级测试两者均达 80.9分，AIME 2025 数学基准 OpenAI 开源模型胜出。这是 OpenAI 首次真正意义开源可商用推理模型，直接对标 Claude 系列。

🔵 GPT-5.6 泄露：内部测试中，预计6月正式发布

OpenAI 内部 Codex 日志（rollout_mapping.json）中发现 GPT-5.6 调用记录，内部代号 ember-alpha / beacon-alpha。首批检查点已启动内部测试，目前大部分请求仍路由至 GPT-5.5（rollout 87.3%），但 GPT-5.6 检查点已被调用。预计2026年6月正式亮相。

⚠️ OpenClaw AI Agent 框架系统性安全漏洞
