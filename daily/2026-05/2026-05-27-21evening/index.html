2. 安全动态：PraisonAI CVE-2026-44338 + 微软/Cisco 高危漏洞

⚠ 开源 Agent 框架漏洞：PraisonAI（开源多智能体编排框架）爆 CVE-2026-44338，CVSS 7.3，属于"缺少认证"类型。PraisonAI 默认配置下 Flask API 服务器认证被禁用，攻击者可在无需 Token 的情况下调用 API 服务器的受保护功能。漏洞公开后数小时内即出现野外利用。

同批高危漏洞（5月14日披露）：

  • CVE-2026-20182：Cisco Catalyst SD-WAN Controller 认证绕过，CVSS 10.0（满分），已有野外利用
  • CVE-2026-20822：微软安全更新（5月24日）
  • CVE-2026-26144：微软 Excel 信息泄露，CVSS 7.5
  • Windows 零日漏洞：BitLocker 绕过 + CTFMON 权限提升，由匿名网络安全研究员披露

OpenClaw 安全通告（GitHub Advisory，5月11日）：GHSA-5mh4-3rv3-fpcf——Host exec 环境清理遗漏包、注册表、Docker、编译器、TLS 覆盖变量，已撤回（可能为重复问题）。

企业 AI 安全态势：根据世界经济论坛《2026年全球网络安全展望》，64%的企业现在会在部署AI工具前进行安全风险评估（去年仅37%）。AI 正在加速漏洞发现和武器化，发现→武器化→利用的 timelines 已被压缩。
